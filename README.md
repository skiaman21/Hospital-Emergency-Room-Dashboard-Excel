# 🏥 Hospital Emergency Room Dashboard — Excel

An interactive **Hospital Emergency Room Dashboard** created in Microsoft Excel to analyze and visualize emergency room patient data.

This project was completed as a **guided project** as part of my learning journey in **Excel and Data Analytics**. It helped me practice data analysis, dashboard creation, and data visualization using Excel.

## 🎯 Project Objective

The main objective of this project is to create an interactive dashboard that provides a quick overview of hospital emergency room performance and patient information.

The dashboard allows users to analyze key metrics and explore patient data by different categories.

## 📌 Key Metrics

The dashboard includes:

* **Number of Patients**
* **Average Wait Time**
* **Patient Satisfaction Score**
* **Patient Attend Status**
* **Patient Gender Distribution**
* **Patient Age Groups**
* **Admission Status**
* **Department Referrals**

## 📈 Dashboard Features

### Monthly Analysis

Users can select a month from **January to December** to view the corresponding emergency room information.

### Year Selection

The dashboard provides a year selection option for comparing:

* 2023
* 2024

### Patient Analysis

Patient information is visualized based on:

* Gender
* Age group
* Admission status
* Department referral
* Attendance status

### Interactive Visualizations

The dashboard uses different Excel visualizations, including:

* KPI cards
* Doughnut charts
* Bar charts
* Area/sparkline-style charts
* Interactive month selection
* Year selection
